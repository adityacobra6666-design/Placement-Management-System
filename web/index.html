Placement Workflow & System Capabilities
End-to-end data processing mapped to Oracle XE schema

• Candidate Profiling: Captures Register Numbers, Degree Department, CGPA scores, and standing backlog counts under strict integrity constraints.

• Corporate Drives: Schedules drives with salary packages (LPA), minimum CGPA cutoffs, and maximum allowable backlog tolerances.

• Eligibility Engine: Automatically evaluates student records against company criteria upon application submission, flagging candidates as ELIGIBLE or NOT ELIGIBLE.

• Application Lifecycle: Supports workflow status transitions (APPLIED → SHORTLISTED → PLACED or REJECTED), updating the core student status synchronously.

Technical Architecture & Integration Pipeline:

1. Frontend Layer
Vanilla HTML5, CSS3, and JavaScript Single Page Application. Communicates with backend endpoints via asynchronous Fetch API requests.
2. Java HttpServer Backend
Lightweight native Java HTTP Server running on Port 8086. Dispatches REST requests, enforces business rules, and outputs structured terminal logs.
3. JDBC Driver Layer
Oracle JDBC Thin Driver (ojdbc6.jar). Establishes optimized TCP/IP socket connections directly to Oracle listener without native client binaries.
4. Oracle XE Database
Oracle Database 11g Express Edition on Port 1521. Schema: PLACEMENT_USER. Tables: STUDENTS, COMPANIES, DRIVES, APPLICATIONS, USERS.
